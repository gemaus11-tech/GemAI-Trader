# GemAI Trader

An AI-assisted cryptocurrency portfolio manager built to help make disciplined, data-driven investment decisions.

## Project Vision

GemAI Trader is designed to:

- Connect securely to CoinSpot.
- Analyse cryptocurrency markets.
- Score investment opportunities.
- Recommend whether to Buy, Hold or Sell.
- Explain every recommendation in plain English.
- Learn from historical performance through testing and refinement.
- Prioritise risk management over frequent trading.
